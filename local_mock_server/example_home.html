How it works

Three steps. One verdict.

  1. 1

    You drop a skill.

    Paste any GitHub repo with a SKILL.md. No tests to write, no setup.

  2. 2

    We run it twice.

    Same task, same seed, same agent. The only thing that changes is whether your skill is loaded.

  3. 3

    You get three numbers.

    Utility, safety, cost — from the same sandbox run, with the receipts to back it up.

What we found

Most public skills don't actually help.

68% of evaluated skills move utility by less than 2 percentage points.

Once tasks are calibrated to the no-skill baseline, paired utility Δ clusters near zero. The few skills that genuinely help tend to cost more and sometimes touch your filesystem or network.
